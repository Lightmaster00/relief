# Relief — brand guide

**Name**: Relief (always written this way).
**Tagline**: *Sound in relief.*

## Icon

A macOS-style icon: a continuous-corner tile (superellipse) with a violet gradient lit by a lagoon
glow (bottom left) and a rose glow (top right), and a white speaker whose three sound waves are
**extruded**, each with its colored side (lagoon, violet, rose): sound in relief.
Generated by `make-icon.py` → `icon.svg` → `icon-*.png` and `AppIcon.icns`.

The menu bar icon (`menubar-icon.svg`, drawn in code in `Brand.swift`) is a template image:
the same speaker and waves, with a lighter offset copy of the waves for the relief, so it can't be
mistaken for the system volume icon.

## Colors

| Name   | Hex       | Use |
|--------|-----------|-----|
| Lagoon | `#22D3C5` | glow, first wave |
| Violet | `#7C5CFF` | tile, second wave |
| Rose   | `#FF5FA2` | glow, third wave |
| Night  | `#12101F` | dark backgrounds (website) |

The interface itself uses the system accent color, like every Mac app; the brand gradient only
appears in the icon, the equalizer curve and the website.

## Files

- `make-icon.py`, `icon.svg` — app icon source (1024 × 1024).
- `menubar-icon.svg` — menu bar icon reference.
- `dmg-background.svg` — installer window background (680 × 400), exported at 1× and 2×.
- `dmg-settings.py` — installer window layout (dmgbuild).
