# Relief — brand guide

**Name**: Relief (always written this way).
**Tagline**: *Sound in relief.*

## Icon

A macOS-style icon: a continuous-corner tile (superellipse), night violet with a soft glow, holding a
**landscape of sound**: three waveform ridges in relief (lagoon at the back, violet, rose in front),
each with a bright edge and a shadow on the layer behind. No speaker: it can't be mistaken for the
system volume icon.
Generated by `make-icon.py` → `icon.svg` → `icon-*.png` and `AppIcon.icns`.

The menu bar icon (`menubar-icon.svg`, drawn in code in `Brand.swift`) is a template image: the same
landscape simplified to two ridges — an outlined one behind a filled one.

## Colors

| Name   | Hex       | Use |
|--------|-----------|-----|
| Lagoon | `#22D3C5` | back ridge |
| Violet | `#7C5CFF` | middle ridge, glow |
| Rose   | `#FF5FA2` | front ridge |
| Night  | `#12101F` | dark backgrounds (website) |

The interface itself uses the system accent color, like every Mac app; the brand gradient only
appears in the icon, the equalizer curve and the website.

## Files

- `make-icon.py`, `icon.svg` — app icon source (1024 × 1024).
- `menubar-icon.svg` — menu bar icon reference.
- `dmg-background.svg` — installer window background (680 × 400), exported at 1× and 2×.
- `dmg-settings.py` — installer window layout (dmgbuild).
